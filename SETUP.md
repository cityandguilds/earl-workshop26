# Setup guide

This guide covers the local setup needed before anyone can use the portal: runtime settings, VM-password encryption, the first administrator, attendees, and VM assignments.

## 1. Install the project

The project requires Python 3.13 and `uv`.

```bash
uv sync
```

## 2. Create the local environment file

Copy the example file. `.env` is ignored by Git, so do not put its contents in source control.

```bash
cp .env.example .env
```

Generate a VM-encryption key with Python's `cryptography.fernet` module:

```bash
uv run python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

Generate a session secret too:

```bash
uv run python -c "import secrets; print(secrets.token_urlsafe(32))"
```

Put both generated values into `.env`:

```dotenv
EARL_WORKSHOP_DATA_DIR=.data
EARL_WORKSHOP_SESSION_SECRET=paste-the-session-secret-here
EARL_WORKSHOP_VM_ENCRYPTION_KEY=paste-the-fernet-key-here
EARL_WORKSHOP_SECURE_COOKIES=false
EARL_WORKSHOP_ENVIRONMENT=development
```

The Fernet key encrypts VM passwords in the SQLite database. Keep it safe and keep using the same key: changing it prevents the portal from decrypting existing VM passwords.

## 3. Load the settings

The application reads environment variables. For Bash, load the local file before each command or add the values to your usual deployment configuration:

```bash
set -a
. ./.env
set +a
```

For an HTTPS deployment, set `EARL_WORKSHOP_SECURE_COOKIES=true`. Production also requires `EARL_WORKSHOP_ENVIRONMENT=production` and a session secret.

## 4. Create the first administrator

Run the CLI command after loading the environment:

```bash
uv run earl-workshop create-admin
```

It prompts for an administrator username, password, and confirmation. Passwords are not supplied on the command line.

The command is provided by the `earl_workshop.cli` Python module. It uses the account helpers in `earl_workshop.auth`; you do not need to write or run a separate Python script.

## 5. Start the portal

```bash
uv run earl-workshop serve
```

Open `http://127.0.0.1:8000/`, sign in as the administrator, and open **Admin**.

## 6. Add attendees and VMs

In **Admin**:

1. Create each attendee. Give them a unique **Sign-in username** and an initial password. A display name is optional and cannot be used to sign in.
2. Create a VM credential with its host/IP, SSH username, and SSH password.
3. Assign the VM credential to an attendee.

The attendee signs in using their sign-in username, then selects **View VM credentials**. Their SSH password remains masked on screen; **Copy password** retrieves it only when they press the button.

## Troubleshooting

- **The application says the encryption key is missing or invalid:** check that `EARL_WORKSHOP_VM_ENCRYPTION_KEY` is set in the shell running the app and is a value generated by `Fernet.generate_key()`.
- **VM credentials are unavailable after a restart:** restore the original Fernet key. A replacement key cannot decrypt passwords stored with the previous key.
- **The administrator command cannot find prior accounts:** check `EARL_WORKSHOP_DATA_DIR` or `EARL_WORKSHOP_DATABASE_PATH`. In a source checkout the default database is `.data/earl_workshop.sqlite3`.
- **An attendee cannot sign in with their name:** use the sign-in username, not their optional display name.
